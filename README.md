# TripWonder · 携程奇境挑战原型

打开 `index.html`，或在本目录运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8765/`。这是可直接在浏览器打开的静态 HTML 原型；当前工作区修改没有自动代表线上部署。

携程首页的 TripWonder 入口直接打开当天第一个待探索目的地的封面；本次页面体验首次进入第一个目的地时自动弹出玩法说明，后续城市不再自动弹，右上角“玩法”可随时手动重开。没有每日目的地列表。每天依据本地日期打乱七座城市（大同、深圳、苏州、桂林、香港、北京、上海）的顺序，全部提供，不从更大的城市池抽取。封面上的“进入探索”和“跳过”并列；跳过后按当天顺序进入下一个待探索目的地。完成挑战后先显示结果，用户可从结果页继续前往下一目的地。七城都完成后可返回首页和图鉴；七城都跳过后回到首页，再次进入会从第一座跳过的城市继续。刷新页面会清空本次挑战、结果、示例权益、收藏及行程，从首页重新开始。

每城有三张探索照片，每张照片一处景点、三个可点击讲解点。探索限时三分钟，支持拖动、双指缩放、滚轮、键盘方向键；画面不显示额外的缩放栏、线索计数、语言切换和提前答题按钮。

三道题各 20 分，提交时只进入下一题、不公布对错。答完后进入地图定位：在中国地图上轻点放置落点，可拖动、双指或滚轮缩放，确认前可反复调整，可回看三处实景及已读线索。确认后地图自动框出落点与真实位置并连线，显示直线距离和定位得分（25 公里内满分 40 分，之后按 450 公里尺度指数衰减；城市可用 `guess` 字段单独配置）。结果页展示综合成绩 = 定位 40 + 三题 60，以及落点、真实位置和距离的小地图。完成后可收藏城市、查看图鉴及今日进度、保存分享卡，并领取清楚标为示例的权益。分享链接可让好友在同一关卡挑战，打开后只在本地对比分数；需要把网页发布到双方都能访问的地址才能跨设备使用。演示好友榜不代表真实用户排名。

路线页使用本地策划的景点和兴趣标签生成一至三日安排，可调天数、节奏、兴趣、出发日期，替换和调整停留地点；保存的行程仅在本次页面体验中可查看。已知的周闭馆日及部分开放时段会用于调换日期分组或标出冲突；未收录的开放时间仍需人工核实。交通时长由两点距离粗估，景点停留时间为规划建议；库存、价格、预订与优惠券兑换均未接入。产品按钮仅演示携程业务承接。

照片集中在 `photo-library/<城市>/<景点>/`；`photos.html` 展示采用素材和署名。大同源图由用户提供，拍摄权属未独立验证。其他城市素材（2026-09-26 素材库更新后的 Pexels 照片与保留的两张 Wikimedia 照片）的作者、许可、识别依据和未采用素材，见各城市的 ATTRIBUTION.md / SOURCES.md。`content/*.js` 是景点、线索、题目和路线站点数据；`catalog.js` 汇总七城并建立媒体索引。每个目的地 1–3 处实景（苏州目前只有虎丘一处），题目固定 3 道；探索页用 `immersive-viewer.js` 沉浸查看，各景配置见 `immersive-scenes.js`。探索时先下载和解码当前图片再切场景，按网络条件预取下一张；图鉴等非沉浸页面使用缩略图。

本轮按用户要求暂缓动态场景和环境声。地图边界来自 DataV.GeoAtlas（`assets/map/`），由 `scripts/build-china-map.cjs` 预投影、简化为 `china-map.js`（约 45 KB，省界 + 省会，四色区分相邻省份）；地级市边界另存为 `china-cities.js`（约 112 KB，363 个地市，直辖市/港澳整体显示，DataV 未提供台湾地市数据），只在放大到一定程度时才加载和显示。运行时不解析 GeoJSON、不加载瓦片；平移只移动一个合成层，地图移动时底部卡片暂停实时模糊。确认落点后地图自动缩放，让落点与答案同时完整可见。距离与计分目前在前端计算，文档中的服务端计分尚未接入。`media.js` 保留未来视频接入所需的海报回退与首帧显现能力，但这版五城内容都只有静态照片，尚无真实景点视频。浏览器及设备实际表现应以目标手机测试为准。
