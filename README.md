# TripWonder 携程 · 奇境挑战

GitHub 仓库：[JasonZhang453625/TripWonder](https://github.com/JasonZhang453625/TripWonder)（私有）。项目仍由仓库所有者管理；需要协作时，在 GitHub 仓库的 Settings → Collaborators 中邀请指定账号。未提供协作者账号前不预先添加成员。

打开 `index.html`，或在本目录运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8765/`。这是可直接在浏览器打开的静态 HTML 原型；当前工作区修改没有自动代表线上部署。

携程首页的 TripWonder 入口打开当天第一个待探索目的地的封面；本次页面体验首次进入封面时自动弹出玩法说明，右上角“玩法”可随时重开。每天依据本地日期，从完整目的地库（当前八座城市）随机抽取五座不同城市，当天顺序固定。封面底部为玻璃工具栏：图鉴、排行榜，以及纯蓝扁平的“进入探索”按钮；没有“跳过”按钮，也没有圆点或滑动提示。直接左右滑动照片可循环切换这五个目的地，桌面可拖动、横向触控板滑动或在照片聚焦后使用左右方向键。切换前等待下一张照片载入，失败时留在当前目的地；切换后返回会保留本次页面体验的场景与线索进度。图鉴与今日成绩沿用这五座城市，完成后可从结果继续下一目的地。好友链接仍支持全库目的地，若不在当天五城中，会替换本次五城中的最后一座以接受挑战。刷新页面仍会清空挑战进度、结果、示例权益、收藏及行程，从首页重新开始，当天抽取的城市保持不变。

各目的地有 1–4 张探索照片，每张照片三个可点击讲解点；张家界包含天子山峰林、云雾峰林、天门洞与通天大道四个场景。探索不限时，左上角返回会直接回到目的地封面，再次进入可继续当前场景。支持拖动、双指缩放、滚轮、键盘方向键；画面不显示额外的缩放栏、线索计数、语言切换和提前答题按钮。

三道题共用两分钟倒计时，每题各 20 分，切题不重置计时；离开答题页停止计时。答题页左上角直接返回刚刚最后一处场景，再次进入答题沿用当前题目、已选答案和剩余时间。到时自动提交当前已选答案，未作答题目计 0 分。提交时只进入下一题、不公布对错。答完或到时后进入不限时的地图定位；答题时间仍有剩余时可返回修改第三题，沿用剩余时间。在中国地图上轻点放置落点，可拖动、双指或滚轮缩放，确认前可反复调整，可回看本目的地全部实景及已读线索。确认后左上角按钮改为返回首页，地图自动框出落点与真实位置并连线，显示直线距离和定位得分（落点与目的地在同一城市（地级市；直辖市、特别行政区按整体计）即满分 40 分；不同城市按距离计分，25 公里内满分，之后按 450 公里尺度指数衰减；城市可用 `guess` 字段单独配置）。结果页展示综合成绩 = 定位 40 + 三题 60，以及落点、真实位置和距离的小地图。完成后可收藏城市、查看图鉴及今日进度、保存分享卡，并分别领取目的地纪念徽章与景点门票优惠券。分享链接可让好友在同一关卡挑战，打开后只在本地对比分数；需要把网页发布到双方都能访问的地址才能跨设备使用。演示好友榜不代表真实用户排名。

结果页分别展示纪念徽章与“优惠权益 · 目的地”两个领取模块，权益位于徽章模块下方，领取状态相互独立。点击“领取权益”打开独立权益弹窗，领取后可再次查看。徽章弹窗只展示城市徽章正面、超越比例与“收下徽章”按钮，保留入场和缩小淡出的退场动画，不再翻转或展示优惠信息。优惠券为满 100 元可用的 20 元景点门票券，前端记录有效期为领取后 30 日；再次查看不延长有效期，记录仍只保存在本次页面体验。领取操作原位更新按钮，不重建结果页，保留展开状态与滚动位置。奖励页的“超越比例”暂由本局分数通过固定曲线估算，并非真实用户成绩统计；优惠券兑换未接入。

路线页使用本地策划的景点和兴趣标签生成一至三日安排，可调天数、节奏、兴趣、出发日期，替换和调整停留地点；保存的行程仅在本次页面体验中可查看。已知的周闭馆日及部分开放时段会用于调换日期分组或标出冲突；未收录的开放时间仍需人工核实。交通时长由两点距离粗估，景点停留时间为规划建议；库存、价格、预订与优惠券兑换均未接入。产品按钮仅演示携程业务承接。

原图统一为 `photo-library/<城市>/<景点>/original.<原格式>`，未采用素材集中在 `photo-library/_unused/<城市>/`；目录与加载规则见 [照片素材规范](photo-library/README.md)。`photos.html` 展示采用素材和署名。大同源图由用户提供，拍摄权属未独立验证。其他城市素材（Pexels、Wikimedia Commons 与 Unsplash 照片）的作者、许可、识别依据和未采用素材，见各城市的 ATTRIBUTION.md / SOURCES.md。`content/*.js` 是景点、线索、题目和路线站点数据；`catalog.js` 汇总八城并建立媒体索引。每个目的地 1–4 处实景（苏州一处，张家界四处，其余三处），题目固定 3 道；探索页用 `immersive-viewer.js` 沉浸查看，各景配置见 `immersive-scenes.js`。探索页使用原图分辨率的沉浸素材，支持最高 3 倍放大；切换时以过渡动画覆盖加载，下一处首帧渲染完成后再显示，失败时保留当前画面并可重试。图鉴等非沉浸页面使用缩略图。

探索页按目的地播放背景音乐：八座城市各一首原创配乐（大同《云冈晨钟》、北京《红墙金瓦》、苏州《姑苏塔影》、桂林《漓水青峰》、张家界《峰林云海》、上海《外滩旧梦》、深圳《湾区之光》、香港《维港夜色》），由 `scripts/build-bgm.cjs` 在本地用纯合成音色（拨弦、笛箫、钟磬、人声、合成器与鼓组）生成，不含采样或第三方录音。运行 `node scripts/build-bgm.cjs --ffmpeg <ffmpeg 路径>` 可重新生成 `assets/bgm/*.mp3`（每首约 0.8–1.1 MB，响度约 −18 LUFS）和 `bgm-manifest.js`。每个文件是一段 60 或 64 秒的循环外加 3 秒交接，`scene-bgm.js` 用 Web Audio 每隔一个循环长度启动一份副本，前后副本重叠后无缝衔接。音乐只在探索页播放，同一目的地内切换场景不中断；离开探索页淡出并暂停，从答题页返回时接着播放。封面会预取当前目的地的音乐（省流量模式除外）。浏览器要求页面先有一次点击或按键才能出声。直接双击打开 `index.html` 时浏览器不允许读取本地文件，播放器改为加载 `bgm-local/*.js`（同一份 MP3 的脚本封装，由同一脚本生成，只供本地预览，不进入网站和 Android 构建）。打开线索时音乐自动压低，朗读线索时进一步压低；收藏按钮左侧的喇叭按钮可开关音乐，选择保存在本机。`check-bgm.cjs` 检查循环衔接、播放、压低、静音与答题往返。

本轮仍暂缓动态场景。地图边界来自 DataV.GeoAtlas（`assets/map/`），由 `scripts/build-china-map.cjs` 预投影、简化为 `china-map.js`（约 45 KB，省界 + 省会，四色区分相邻省份）；地级市边界另存为 `china-cities.js`（约 112 KB，363 个地市，直辖市/港澳整体显示，DataV 未提供台湾地市数据），只在放大到一定程度时才加载和显示。运行时不解析 GeoJSON、不加载瓦片；平移只移动一个合成层，地图移动时底部卡片暂停实时模糊。确认落点后地图自动缩放，让落点与答案同时完整可见。距离与计分目前在前端计算，文档中的服务端计分尚未接入。`media.js` 保留未来视频接入所需的海报回退与首帧显现能力，但这版各目的地内容都只有静态照片，尚无真实景点视频。浏览器及设备实际表现应以目标手机测试为准。
