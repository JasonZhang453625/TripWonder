# 高清照片空间探索 demo

从仓库根目录启动静态服务器后访问 `/demos/immersive-photo/`。独立实验入口，未接入正式游戏流程。

使用现有天子山照片（源图 8841 × 4415），WebGL 纹理上限不足时使用已有 2400px detail.webp。人工绘制近似深度场，通过有界纹理位移模拟小范围视差；没有生成真实 3D、360° 全景或照片之外的景物。近似深度会带来局部形变，不能视为已完成分层或精确重建。

支持原图/空间探索切换、拖动、方向键、深度调节、可选巡游、三个线索和目的地选择。巡游默认关闭并遵循减少动态效果设置。WebGL 不可用时保留静态图与线索。手机使用横向拖动探索，页面仍可纵向滚动。

照片署名、来源、许可详见页面底部及 `../../photo-library/zhangjiajie/ATTRIBUTION.md`。照片衍生效果沿用 CC BY-SA 4.0。未改变原图、题库、正式查看器、依赖或线上配置。
