# 横向高清照片 → 手机球幕预览工作流

## 适用范围

输入为横向实景照片，输出为手机竖屏、高宽 18:9 的纯图片交互窗口。摄影机固定在球心，拖动改变观看方向；不使用深度图、不生成照片外的内容。此目录提供独立 demo；正式游戏查看器的接入契约见 [正式球面照片流程](../../docs/sphere-photo-workflow.md)。当前仍无图片上传后台；此实现不是 CGV SphereX 官方实现。

## 1. 放置来源图

按仓库素材规范，将照片放在 `photo-library/<城市>/<场景>/original.jpg`（也支持 `.png`、`.webp`），保留原片和来源记录。工作流不修改、不裁切原文件。

必须是按 EXIF 显示方向计算后宽大于高的图片。建议原图长边至少 2400px；低分辨率横图可以预览，但不能因此视为高清合格。当前流程支持 JPEG、PNG、WebP；其他格式需先另存浏览器兼容展示副本并保留原片及来源记录。

## 2. 登记配置

在本目录 `sphere-inputs.json` 加入一条记录。路径相对于仓库根目录：

```json
{
  "id": "my-landscape",
  "name": "场景名称",
  "image": "photo-library/my-city/my-scene/original.jpg",
  "credit": "摄影者或用户提供",
  "source": "照片来源页或提供方式",
  "license": "照片使用许可或授权说明"
}
```

可以另加 `fallback`（同构图、同比例的较小展示图）和 `licenseUrl`。不填 fallback 时沿用原图；设备纹理上限不足时，浏览器按上限等比缩绘上传纹理，原图文件不变。已有五个例子复用素材库的 `detail.webp`，小设备无需解码完整超大图。

ID 只能含小写英文字母、数字和连接号，且不可重复。图片与回退图都必须在仓库内。署名等元数据保存于配置和辅助技术可读内容，画面不显示文字。

## 3. 检查并生成

环境：Python 3.10+、Pillow；浏览器预览不需要 Python 图片处理库。若 Python 尚无 Pillow，可在自己的虚拟环境安装 `python -m pip install Pillow`。

在仓库根目录运行：

```sh
python3 demos/immersive-photo/workflow.py
```

命令检查文件可读性、EXIF 方向、横图条件、重复 ID、必填署名、回退图比例，记录像素尺寸和 SHA-256，再生成 `scenes.js`。全部检查通过后才写生成文件。不要手工编辑生成文件。

要只检查配置是否仍与图片一致：

```sh
python3 demos/immersive-photo/workflow.py --check
```

## 4. 打开手机预览

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8766/demos/immersive-photo/?scene=my-landscape`。缺少 ID 或 ID 不存在时打开第一张图。界面只显示当前照片，拖动观察、双击复位；方向键用于桌面检查。通过不同链接切换场景，不在画面添加切换按钮。

使用不同电脑测试真实手机时，需要另行提供手机可访问的本地网络地址；127.0.0.1 只能从当前电脑访问。本流程的浏览器模拟结果不代表真机验收。

## 5. 自动参数与降级

- 水平球面覆盖最多 150°；垂直覆盖按图片比例计算并限制为最多 100°，避免球极。
- 默认垂直视场角最多 58°，超宽横图会自动缩小视场角，确保视野被原片覆盖。
- 计算转头极限，让视口的四角仍位于原照片内；不以重复、镜像或 AI 补景填充边缘。
- 图片加载失败时尝试回退图；纹理过大时使用回退图或等比缩绘；WebGL 不可用时显示静态图。
- 两个源文件都不可访问时无法展示该场景，应修正素材，不用其他城市图片替代。

## 6. 验收

```sh
python3 demos/immersive-photo/workflow_test.py
node --test demos/immersive-photo/sphere-math.test.cjs
node demos/immersive-photo/check-browser.cjs
```

浏览器检查需要本机安装 Chrome 和 Playwright。Playwright 不在项目模块路径时用 `PLAYWRIGHT_PATH` 指向其模块目录；Chrome 路径可用 `BROWSER_PATH` 指定。服务端地址可用 `DEMO_URL` 指定，截图输出目录用 `SPHERE_QA_DIR` 指定，默认写系统临时目录，不写入 Git。

自动检查覆盖五图的中心与左右极限截图、触屏拖动改变画面、纯图片界面、两种手机尺寸、WebGL 错误和静态回退。几何测试另外覆盖近方形横图到 8:1 超宽图；这些合成比例测试不代表已用真实 8:1 素材做视觉验收。

人工检查中心、左右极限、上下转头：主体是否可辨、直线是否过度弯曲、初始构图是否合适、画质是否足够。竖屏窗口只展示横图的一部分，需转头才能观察更多内容。自然风景通常较容易容忍投影形变；建筑立面、文字和长直线应重点核对。横屏格式本身不能保证视觉质量。
